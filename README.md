# John Matthew Robles — Angular CV Portfolio

A minimal, project-index portfolio inspired by the restrained presentation of seyityilmaz.com. The layout uses a compact header, small introductory metadata, a simple project grid with year labels, and concise About / Skills details.

## Run
1. Use a compatible Node.js version for the installed Angular CLI.
2. Run `npm install`
3. Run `ng serve`
4. Visit `http://localhost:4200`
